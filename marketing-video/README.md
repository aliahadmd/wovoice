# WoVoice marketing video

Editable Remotion source for the 25-second WoVoice portfolio video. It uses the real app screenshots, local transition sound effects, and a 1920×1080 H.264 composition.

## Preview

```sh
npm install
npm run dev
```

## Validate and render

```sh
npm run lint
npx remotion render WoVoice-Marketing out/wovoice-marketing.mp4
```

The rendered portfolio copy is stored at `docs/portfolio/wovoice-marketing-video.mp4`.
